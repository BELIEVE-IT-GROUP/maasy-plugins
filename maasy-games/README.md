# maasy-games

Plugin de Claude para Maasy Games: juegos de marca que se juegan en el celular. Agrega los comandos
`/maasy-games:*` y conecta el servidor `https://games.maasy.ai/mcp`. Pide iniciar sesión con tu cuenta de Maasy.

Instalar:

```
/plugin install maasy-games --marketplace BELIEVE-IT-GROUP/maasy-plugins
```

| Comando | Qué hace |
|---|---|
| `/maasy-games:nuevo` | Un juego nuevo |
| `/maasy-games:cambio` | Cambiar un juego que ya existe |
| `/maasy-games:probar` | Probarlo y empaquetarlo en el servidor |
| `/maasy-games:publicar` | Guardar la versión, sacar el link de prueba y mandarla a aprobar |
| `/maasy-games:proponer` | Proponer la pauta en BeAds |
| `/maasy-games:estado` | Ver cómo va |

La marca se lee con el plugin `maasy`. La tab Games la dibuja el panel de `maasy`. Lo público necesita la aprobación de
la persona dueña de la marca, en la sección Games de Maasy, en https://vibe.maasy.ai.
