# Glosario

Las palabras que más se repiten en este manual, en una línea cada una.

| Palabra | Qué significa |
|---|---|
| ADN de marca | Lo que Maasy sabe de tu marca: identidad, propuesta de valor, cliente ideal, voz, estilo visual y prueba social |
| Anti-Look Maasy | El circuito de la web de Maasy que toma tus referencias visuales y arma tu design system y tus bibliotecas de ambientes y escenas |
| APS | Agent Preference Score. Qué tanto te prefieren los modelos de IA. Hay uno declarado (lo que tu sitio dice) y uno medido (lo que los modelos responden) |
| AOS | Agent Operability Score. Qué tan operable es tu sitio para agentes de IA |
| Borrador | Algo que Claude preparó y que todavía no salió al mundo. Nada se envía desde Claude |
| Canvas | La bandeja de la web de Maasy donde llegan las piezas de tus plugins y tú las apruebas o descartas |
| Cerebro | La memoria de tu marca en Maasy: el ADN y las piezas que aprobaste y descartaste |
| Control plane | La web de Maasy vista como panel de control: marcas, ADN, canvas, CRM, llaves y plan |
| Derivación | Lo que el sistema genera por ti a partir de tus respuestas: ángulos de venta, pilares, design system y otros |
| design.md | Un documento con las reglas visuales y de voz de tu marca, que los plugins leen antes de crear |
| Franja | La barra corta sobre el cuadro de texto de Claude que dice en qué modo estás |
| MCP | Cómo se conecta Claude a Maasy y a sus plugins. No tienes que configurarlo: lo hace el plugin |
| Panel | La columna a la derecha de la conversación, con una pestaña por plugin |
| Plugin | Un complemento de Claude. Hay uno núcleo (`maasy`) y uno por producto |
| Pro | El plan de pago de Maasy en Claude, por marca |
| Receta | El método de Maasy para una tarea (la entrevista, un video). Se sirve desde Maasy tras iniciar sesión, no viaja en el plugin |
| Tarjeta | Dos cosas. En el chat, una pregunta con opciones para elegir. En el canvas, una pieza que espera tu decisión |
