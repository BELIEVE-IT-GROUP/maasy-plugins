# Proyecto creado con Believable

Levanta el preview con `npm run dev` (Believable lo hace solo al abrir el proyecto).

Stack: TanStack Start (Vite 7 · React 19) · TypeScript · Tailwind CSS v4 · componentes
estilo shadcn.

Las rutas viven en `src/routes/` (una por archivo). `npm run build` deja el sitio ya
renderizado en `dist/client/`: cada ruta sale como HTML completo, legible por buscadores
y agentes sin ejecutar JavaScript.
